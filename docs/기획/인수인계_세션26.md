## 3. 이번 세션에서 발견해 고친 결함 (재발 방지)

### 3.1 [CRITICAL] 국채 자동 시세갱신 3중 결함 — 되살리면 이력이 파괴될 뻔했다
```
① order='start.asc'   → 실제 컬럼은 start_date → 400. catch{} 에 삼켜져 무동작.
② restSelect 결과를 camelCase 로 읽음 → bondTicker 등 전부 undefined → 필터 전량 탈락.
③ ⚠ 조회된 '모든 행'을 같은 최신 기준가로 UPDATE.
   국채는 기준일마다 새 행이 쌓이는 구조(72건)라, ①②만 고쳤다면 전부 뭉개졌을 것.
해결: getLatestBonds() 로 종목별 최신 1건 → 새 행 INSERT (지분 갱신과 동일 패턴).
금지: 국채를 기존 행 UPDATE 로 갱신하지 말 것.
```

### 3.2 폴백값이 통화를 가리지 않고 적용됐다
메디아나면 EUR·JPY·GBP 에도 월 300만·버퍼 250만이 적용돼 해당 통화의 버퍼 하한이
근거 없이 올라갔다(= 환전을 덜 하게 됨). → `regimeOpsFallback(company, currency)` 로 USD 한정.

### 3.3 화면(0)과 엔진(300만)이 달랐다
정책 기준 탭이 미설정을 0 으로 보여줘 회의체가 실제 적용값을 알 수 없었다.
→ placeholder 에 `3,000,000 (기본값 적용 중)` 노출.

### 3.4 로컬 자정 Date + toISOString = 하루 밀림
`new Date('...T00:00:00')` 는 로컬 자정이라 KST 기준 전날이 나온다. 테스트가 잡음.
⚠ 단 `get12Weeks/getMonday` 는 **이미** 이 시프트를 가진 채 `week_start` 를 저장해 왔다.
저장·조회가 같은 함수라 자체적으로는 일관되므로 "고치면" 오히려 어긋난다 —
산출 기준 주는 반드시 `get12Weeks()[0]` 을 그대로 쓸 것.
