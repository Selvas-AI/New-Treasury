# 환율 국면 — 수준(Level) 축 도입 설계

> 작성: 2026-08-11
> 배경: 기존 국면 판정은 **추세×변동성** 2축뿐이라 "지금이 비싼가 싼가"를 판단할 수 없었다.
> 그 결과 상승장(=고가)에 목표 보유비중을 올려 **고가 매도를 억제**하고,
> 하락장(=저가)에 목표를 내려 **저가 매도를 강제**하는 역효과가 있었다.
> 선행 문서: [`환율국면_인수인계.md`](환율국면_인수인계.md)

## 0. 확정된 전제 (사용자 결정, 2026-08-11)

| # | 항목 | 결정 |
|---|---|---|
| 1 | **목적함수** | **실현환율 극대화**. 리스크는 정책밴드로 제약. (기존 문서의 "헷지비율 최소화"가 아님) |
| 2 | **기준 수준(앵커)** | 최근 3년 중 **가장 횡보했던 구간의 평균 환율** |

## 1. 왜 Level 축이 필요한가

사용자 요구를 분해하면 두 개의 독립된 개념이 섞여 있다.

- "환율이 **높은 수준**에 있을 때 실현한다" → **Level** (비싼가/싼가)
- "**강한 하락**장이다" → **Trend** (오르는 중인가/내리는 중인가)

높은 수준에서 하락할 수도, 낮은 수준에서 하락할 수도 있다. 기존 엔진은 **후자만** 본다.

**7월 사고와의 정합성 검증**

| 2026-07 초, 환율 1,531원 (연중 최고) | 판정 | 결과 |
|---|---|---|
| 기존 모멘텀 로직 | ①강한 상승 → 목표 45% → **보유 유지** | 실무진이 실제로 한 행동과 동일 → **사고 재현** |
| Level 로직 | 앵커 대비 크게 높음 → **대량 환전** | 사고 방지 |

→ Level 축이 이 프로젝트의 원래 목적(매각 시기 놓침 방지)을 직접 달성한다.

## 2. 앵커(기준 수준) 산출 — "가장 횡보했던 구간"

### 2.1 조작적 정의
"좌우로 가장 횡보했던 구간" = **밴드 폭이 좁고(range), 시작점으로 되돌아온(ER 낮음)** 구간.

```
findConsolidationZones(closes, dates, {
  lookbackDays = 750,   // 최근 3년
  windowDays   = 60,    // 박스 판정 창 (정책 파라미터)
  topN         = 3,
})

각 윈도우 w 에 대해:
  rangePct = (max(w) - min(w)) / mean(w)        // 폭 — 좁을수록 횡보
  er       = efficiencyRatio(w, windowDays-1)   // 0~100 — 낮을수록 제자리
  mean     = 평균 환율                           // ← 앵커 후보값

정렬: rangePct 오름차순 (1차), er 오름차순 (2차)
겹침 제거: 이미 선택된 후보와 겹치는 윈도우는 건너뜀 (non-maximum suppression)
반환: 상위 topN 개 { from, to, mean, min, max, rangePct, er }
```

> ✅ `efficiencyRatio()` 는 **이미 `fxRegime.ts` 에 있다.** 신규 지표 개발 불필요.
> ER 은 "순이동 / 총이동"이라 정확히 "제자리 왕복 정도"를 재는 지표다.

### 2.2 ⚠ 함정 1 — 앵커가 저절로 튀면 안 된다
데이터가 하루 늘 때마다 "가장 횡보한 구간"이 다른 곳으로 바뀔 수 있다.
앵커가 점프하면 목표 비중이 점프하고 → **불필요한 매매가 발생**한다.

**대응**: 앵커를 **자동 적용하지 않는다.**
- 시스템은 후보 3개를 **제시**만 한다 (구간·평균·폭·ER 표시)
- 담당자가 선택 → `policy_params.fx_level_anchor_krw` 에 **고정 저장**
- 정책회의 의결 대상으로 다루고, **분기 1회 재검토**
- 재계산 버튼은 두되, 누르기 전까지 앵커는 절대 바뀌지 않는다

### 2.3 ⚠ 함정 2 — 구조적 드리프트
원/달러는 2022~2026 동안 추세적으로 상승했다(약 1,190 → 1,541).
2~3년 전 박스권 평균을 앵커로 고정하면 **"현재는 영원히 고가"** 로 판정되어
알고리즘이 항상 최대 매도만 권고하게 된다 → 국면 판정의 변별력이 사라진다.

**대응**: 앵커 노후화 경보
- 앵커 설정일로부터 경과일 표시
- 최근 N개월(기본 6) 동안 편차가 계속 한쪽(예: +10% 초과)에 머물면
  **"앵커 재검토 필요"** 배너 표시
- 후보 탐색 시 최근 구간에 가중치를 두는 옵션 제공(기본 off — 판단은 사람이)

### 2.4 ⚠ 함정 3 — 앵커 하나로 모든 걸 결정하지 말 것
박스권 평균은 **참조점**이지 정답이 아니다.
화면에 항상 **함께** 표시할 것: 현재가 / 앵커 / 최근 1년 최고·최저 / 3년 백분위.
담당자가 앵커만 믿지 않고 교차 확인할 수 있어야 한다.

## 3. Level 등급과 목표 비중

### 3.1 편차 → 등급
```
dev = (현재환율 − 앵커) / 앵커
```

| 등급 | 조건 (기본값, 정책 파라미터) | 의미 |
|---|---|---|
| `VH` 매우 높음 | dev ≥ +8% | 적극 실현 구간 |
| `H`  높음 | +3% ≤ dev < +8% | 실현 |
| `N`  중립 | −3% < dev < +3% | 정기 환전 유지 |
| `L`  낮음 | −8% < dev ≤ −3% | 환전 최소화 |
| `VL` 매우 낮음 | dev ≤ −8% | 보유 (필수분만) |

### 3.1-b 운용 폭 결정 (2026-08-11 실측)

초기안(10~45%)이 극단적이라는 지적에 따라 폭을 줄여가며 성과를 측정했다.
중립 30% 고정, 편차만 축소. 앵커 1,378, 정책밴드 해제.

| 운용 폭 | 2025~ 프리미엄 | 2026-07~ 프리미엄 | 판정 |
|---|---:|---:|---|
| 10 ~ 45% | +21.2원 | +52.9원 | 최대 효과 |
| **15 ~ 42%** | **+19.5원** | **+48.6원** | ✅ **채택** — 폭 23%↓, 효과 8%↓ |
| 18 ~ 39% | +16.9원 | +40.8원 | 효과 20%↓ |
| 22 ~ 36% | +13.2원 | +9.6원 | 고점 포착 실패 시작 |
| 24 ~ 34% | +10.6원 | **−46.0원** | 기간평균보다 나쁨 |
| 26 ~ 33% | +8.5원 | 거래 0건 | 시스템 무력화 |

**좁히면 무너지는 이유**: 목표와 현재 비중의 차이가 리밸런싱 밴드를 넘지 못해
고점에서 충분히 팔지 못하고, 남은 물량을 나중에 더 싸게 팔게 된다.

**부수 효과**: 폭을 줄이면 덜 팔게 되어 기말 미환전 잔량이 늘어난다
(2026-07 구간 12.0M → 13.8M). 노출 한도 설정이 더 중요해진다.

**참고**: 2025년 백테스트에서 실제 사용된 목표는 15~30% 구간이었다.
극단값은 이론적 경계일 뿐이며, 결제 버퍼·정책 밴드·노출 한도가 다시 제약한다.

### 3.2 ⭐ Level × Trend 매트릭스 — Level 이 방향, Trend 가 속도

목표 외화 보유비중 = **`base(level)` 를 `modifier(trend)` 가 조정**한다.
Trend 를 버리지 않고 **속도 조절기**로 남기는 것이 핵심이다.

| | 상승 추세 (①②) | 횡보 (③) | 하락 추세 (④⑤) |
|---|---|---|---|
| **VH 매우 높음** | 분할 매도(트레일링) | 적극 매도 | **⭐ 즉시 전량 환전** |
| **H 높음** | 분할 매도 | 매도 | 적극 매도 |
| **N 중립** | 정기 환전 | 정기 환전 | 정기 환전 |
| **L 낮음** | 보유 | 최소 환전 | 최소 환전 + 노출 감시 |
| **VL 매우 낮음** | 보유 | 보유 | 보유 + **상한 감시 강화** |

- **가장 강한 매도 신호 = 높은 수준 + 하락 전환** → 2026-07 상황이 정확히 여기 해당
- 낮은 수준에서는 하락 추세여도 매도를 강제하지 않는다 (기존 로직의 저가 매도 강제 제거)

### 3.3 ⚠ 안전장치 — 순수 역추세의 함정
"싸니까 안 판다" 는 곧 "오를 때까지 기다린다" 이고, 그게 **7월에 실무진이 한 판단**이기도 하다.
구조적 하락이면 순수입 구조상 재고가 무한 누적된다. 따라서 **Level 만으로 매도를 중단시키지 말 것**:

1. **정책밴드 상한은 절대 우선.** 비중이 상한을 넘으면 Level 과 무관하게 환전한다.
2. **시간 기반 강제 환전.** 미환전 잔량이 일정 기간(기본 90일) 이상 방치되면
   Level 이 낮아도 최소 비율을 환전한다. ("기다림"이 무한정 되지 않게)
3. **최대 노출액 상한.** 미환전 잔량이 한도를 넘으면 강제 환전.

## 4. 취득원가 축 — 손실 실현 경고 (결정 #3)

### 4.1 정책
**차단하지 않는다.** 비중 축소가 필요하면 원가 이하라도 매도해야 한다.
대신 **얼마를 손실 실현하는지 반드시 명시**한다.

### 4.2 계산
```
실현손익 = (매도환율 − 평균취득환율) × 매도수량
```

### 4.3 데이터 출처 (단계적)
| 단계 | 취득원가 출처 | 상태 |
|---|---|---|
| 1 (현재) | **수동 입력** — `fxRegimeInputs` 에 `avgAcquisitionRate` 추가 | 즉시 구현 |
| 2 (추후) | FIFO/가중평균 외화원장 연동 (`docs/기획/외화원장_FIFO_가중평균.md`) | 별도 기획 존재 |

> 순수입 기업의 "취득원가"는 수출대금을 수취한 시점의 환율이다.
> 정확히 하려면 원장이 필요하지만, 가중평균 수동 입력으로도 실무 판단에는 충분하다.

### 4.4 표시 요구사항
- **판정 화면**: 권고 매도 실행 시 예상 실현손익을 함께 표시.
  손실이면 노란 경고: `⚠ 이 환전은 약 X억원의 환차손을 실현합니다 (취득 1,4XX → 매도 1,4XX)`
- **백테스트**: 누적 실현손익을 손실/이익 분리해 리포트
- 손실 실현이더라도 **왜 해야 하는지**를 함께 보여줄 것
  (예: "비중 상한 초과 해소" / "노출 한도 초과") — 근거 없는 손절로 보이면 실행되지 않는다

## 4.5 ✅ 검증 결과 (2026-08-11, 실데이터 USD 1,130건)

### Out-of-sample 백테스트 — 앵커를 **검증 구간 이전 데이터로만** 산출

> ⚠ 앵커를 전체 데이터에서 뽑으면 검증 구간 안의 정보를 쓰게 되어(look-ahead) 결과가 낙관 편향된다.
> 아래는 각 시작일 이전 데이터로만 앵커를 뽑아 재검증한 값이다.
> 조건: 초기 912.9억/14.34M USD, 월 유입 3.0M, 버퍼 2.5M, 주 1회 점검, 10bp, **정책밴드 해제**(순수 알고리즘 효과)

> 아래 수치는 **최종 채택 매트릭스(15~42%)** 기준으로 재산출한 값이다.

| 검증 구간 | 앵커 | 기간평균 | **수준×추세** | **구 로직** | 차이 |
|---|---:|---:|---:|---:|---:|
| 2024-01~ | 1,317.3 (2023 박스) | 1,414.1 | **1,432.7** (+18.7) | 1,409.0 (**−5.1**) | **+23.7원** |
| 2025-01~ | 1,378.0 (2024-05~08 박스) | 1,445.3 | **1,464.9** (+19.5) | 1,440.7 (**−4.6**) | **+24.2원** |
| 2026-07~ | 1,378.0 | 1,479.8 | **1,528.4** (+48.6) | 1,448.7 (**−31.1**) | **+79.7원** |

### 핵심 발견
1. **구 로직은 세 구간 모두 기간평균보다 못한 환율에 팔았다** (−5.1 / −4.6 / −31.1원).
   모멘텀 추종이 실제로 **저가 매도를 유발**한다는 것이 실측으로 확인됐다.
2. **수준 축은 세 구간 모두 기간평균을 상회**했다 (+19.0 / +21.2 / +52.9원).
3. **2026-07 구간에서 실현환율 1,532.7원** — 당시 고점(약 1,541원) 부근에서 환전했다.
   같은 구간 구 로직은 1,448.7원. **1달러당 84원 차이.**
4. 앵커가 1,318.5 / 1,378.0 으로 달라져도 결론이 동일 → **앵커 민감도가 낮다**(좋은 신호).

### 확인된 트레이드오프
수준 축은 저가 구간에서 환전을 미루므로 **미환전 잔량이 더 커질 수 있다**
(2026-07 구간: 12.0M vs 구 로직 8.5M). §3.3 안전장치(노출 상한·시간 기반 강제 환전)가
장식이 아니라 필수인 이유다. 실전 적용 시 최대 노출 한도를 반드시 설정할 것.

### 앵커 민감도 — 후보별 성과 비교 (정책밴드 해제 조건)

| 앵커 | 현재가(1,415.3) 등급 | 7월 고점(1,554.4) 등급 | 2025-01~ 프리미엄 | 2026-07~ 프리미엄 | 기말 미환전 |
|---:|:---:|:---:|---:|---:|---:|
| **1,378.0** | 중립 (+2.7%) | **VH** | **+21.2원** | **+52.9원** | 12.0M |
| 1,453.3 | 중립 (−2.6%) | H | +19.4원 | +46.8원 | 16.7M |
| 1,330.5 | 높음 (+6.4%) | VH | +12.7원 | +19.9원 | 7.7M |

**핵심**: 낮은 앵커(1,330.5)는 모든 시점이 &ldquo;고가&rdquo;로 읽혀 **너무 일찍 팔아** 성과가 가장 나빴다.
§2.3 에서 경고한 구조적 드리프트 함정이 실측으로 확인된 것이다.
반대로 높은 앵커(1,453.3)는 성과는 비슷하나 **미환전 잔량이 39% 더 크다**(노출 리스크).

### ⚠ 순위 산정 기준 수정 (2026-08-11)
초기 구현은 **밴드 폭만으로** 정렬해 1,330.5(폭 2.80% / ER 15.5)를 2순위로 올렸으나,
위 표대로 실제 성과는 최하위였다. 폭이 좁아도 그 안에서 방향성이 있으면(ER 높음)
&ldquo;합의된 가격대&rdquo;가 아니라 완만한 추세 구간이라 앵커로 부적합하다.
→ **종합 점수 = 폭(%) + ER/10** 으로 정렬하도록 수정. 성과 순서와 일치함을 확인했다.

### 현재 후보 (수정된 기준, 2026-08-11)
| 순위 | 구간 | 평균 | 폭 | ER | 현재가 등급 |
|:--:|---|---:|---:|---:|:---:|
| **1** | 2024-05-23 ~ 2024-08-16 | **1,378.0** | 2.22% | 0.7 | 중립 (+2.7%) |
| 2 | 2024-12-31 ~ 2025-04-01 | 1,453.3 | 2.90% | 0.2 | 중립 (−2.6%) |
| 3 | 2025-05-22 ~ 2025-08-18 | 1,375.0 | 3.40% | 1.6 | 중립 (+2.9%) |

**권장: 1순위 1,378.0원.** 폭·ER 모두 최상위이고 out-of-sample 성과도 가장 좋았다.
3순위 1,375.0 은 값이 사실상 동일(차이 3원=0.2%)하면서 **1년 더 최근** 구간이라,
앵커 노후화가 우려될 때 대체안으로 적합하다.
